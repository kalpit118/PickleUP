# Feature Roadmap

## Phase 0 — Product Definition

- Finalize terminology: game, match, set, tournament, team
- Define scoring rules
- Define verification/dispute behavior
- Define player rating approach
- Define privacy rules
- Finalize database schema

## Phase 1 — MVP Foundation

- React + TypeScript + Vite
- Responsive UI
- PWA manifest/service worker
- Supabase project
- Authentication
- Profile
- Basic navigation

## Phase 2 — Core Match System

- Create game
- Add players
- Score entry
- Score submission
- Match verification
- Match history
- Basic player statistics

## Phase 3 — Social

- Search players
- Friend requests
- Friends list
- Groups
- Game invitations
- Notifications

## Phase 4 — Tournaments

- Create tournament
- Player registration
- Round robin
- Single elimination
- Match generation
- Standings
- Brackets
- Public tournament page

## Phase 5 — Analytics

- Rating
- Rating history
- Head-to-head
- Partner statistics
- Win-rate trends
- Point differential
- Tournament history
- Performance dashboard

## Phase 6 — Growth Features

- QR score entry
- Challenges
- Activity feed
- Push notifications
- Shareable player cards
- Club dashboard

## Phase 7 — Optional Native Packaging

- Android APK using Capacitor or equivalent
- Native iOS app only if there is a demonstrated product need and budget
