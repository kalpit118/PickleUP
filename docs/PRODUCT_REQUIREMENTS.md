# Product Requirements Document

## 1. Product Summary

A social and competitive pickleball platform for recording games, managing friends and groups, running tournaments, and understanding player performance.

## 2. Target Users

### Primary
- Amateur pickleball players
- Local pickleball groups
- Club players
- Tournament organizers

### Initial Focus

Start with small clubs/groups of roughly 20–100 players. Optimize for repeated match recording rather than trying to serve every pickleball use case immediately.

## 3. Core Features

### Accounts
- Email/password authentication
- Optional Google authentication if supported within the free infrastructure
- Profile creation
- Avatar
- City
- Playing level
- Singles/doubles preference

### Games and Matches
- Create a game
- Add/invite players
- Singles and doubles
- Enter scores
- Submit result
- Opponent/team confirmation
- Dispute result
- Match history
- Match details

### Friends and Groups
- Search players
- Add/remove friends
- Accept/reject requests
- Create groups
- Invite players to games
- View group activity

### Tournaments
- Create tournament
- Register players
- Singles/doubles support
- Round robin
- Single elimination
- Later: double elimination and pool → knockout
- Generate matches
- Enter scores
- Standings
- Brackets
- Public tournament page

### Analytics
- Games played
- Wins/losses
- Win rate
- Points won/lost
- Point differential
- Winning/losing margins
- Current/best streak
- Head-to-head record
- Partner statistics
- Tournament statistics
- Rating history

## 4. Future Features

- QR-based score entry
- Public spectator links
- Push notifications
- Challenges
- Activity feed
- Advanced player rating
- AI-generated performance insights
- Club administration
- Court management
- Court booking integrations
- DUPR integration if technically and commercially appropriate

## 5. Non-Goals for MVP

- Native iOS application
- Paid court-booking marketplace
- Complex payment infrastructure
- AI coaching
- Full professional tournament management suite
- Large-scale social network functionality

## 6. Core User Journey

1. User signs up.
2. User creates profile.
3. User adds friends or joins a group.
4. User creates a game.
5. Players join the game.
6. Players play the match.
7. One player submits the score.
8. Relevant opponent/team confirms it.
9. Match becomes verified.
10. Match history and statistics update.
11. Rating updates if enabled.
12. Players can view analytics and start another game.
